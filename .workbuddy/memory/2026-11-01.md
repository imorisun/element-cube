## 元素立方 · 交互式元素周期表（element-cube）

从零构建的 Vue 3 + TypeScript + Vite 8 + Three.js 学习网站。

### 功能
- 118 元素数据 `src/data/elements.ts`（紧凑 `|` 分隔 RAW 文本，加载时解析；含中文名、物性、用途、简介）
- 三种视图：周期表（18 列 + 镧系/锕系分栏）/ 列表（按分类分组）/ 3D 立方（柱高映射属性）
- 搜索支持中英文名/符号/序数/分类名；分类多选筛选；悬停高亮同行同族
- 详情面板含 3D 原子模型（质子/中子核 + 电子层轨道动画，拖拽/缩放/自动旋转）
- 深浅色主题切换（记忆偏好）、桌面/移动端响应式、快捷键（/ 搜索、←→ 切换、Esc 关闭）

### 关键技术决策
- three.js 体积大 → `defineAsyncComponent` 按需异步加载 AtomModel3D/TableCube3D，首屏 gzip 仅约 55KB
- 网格位置在数据文件 `computeGrid` 中计算（镧系行10、锕系行11，含族/周期轴）
- 3D 用 InstancedMesh 渲染核子与电子保证性能

### 测试
- `scripts/smoke.mjs`：CDP 驱动无头 Edge 的 25 项交互冒烟测试（全部通过）
- `scripts/shots.mjs`：各视图截图脚本
- 无头浏览器需 `--enable-unsafe-swiftshader` 才能跑 WebGL

## 3D 模型排查与优化（同日二轮）

### 修复的正确性 / 稳定性缺陷
- **WebGL 上下文泄漏**：仅 `renderer.dispose()` 不归还上下文，反复打开详情面板会撑爆 16 个上限 → 抽出 `teardownRenderer()` 统一 `dispose + forceContextLoss`
- **共享几何体被重复 dispose**：118 个立方体共享 1 个 BoxGeometry、各电子层共享 electronGeo，逐个 dispose 会反复派发事件 → `disposeSubtree()` 用 Set 去重
- **质子/中子分布错误**：旧实现沿螺旋先填质子后填中子（两级分居）→ 改为累计取整交错分布
- **每帧读取 TorusGeometry.parameters**：改为构建期缓存半径
- **时间跳变**：改用仅可见时累加的 simTime，切元素不再导致电子瞬移
- **相机构图**：改用按 FOV 精确计算适配距离并保留用户视角方向，移动端竖屏不再裁切
- **新增 webglcontextlost 处理**：显示提示并提供「重新渲染」按钮（完整 shutdown+boot 重建）

### 性能优化（实测）
- **118 张独立贴图 → 单张图集**：2048×1024 canvas（16×8 格），每立方体用 clone + offset/repeat；three 按 texture.source 复用 1 个 WebGLTexture（renderer.info.textures 从 118+ 降到 29≈1 图集+28 标注）
- **原子模型纹理累积**：文字标注改为「模型树持有、随模型销毁」（cache:false），往返切换 40 个元素后 textures 从 82 回落到基线 7
- 悬停拾取每帧最多一次；材质高亮/柱高动画改脏检查驱动；PerfGuard 掉帧自动降像素比
- 实测：周期表 147 draw calls / 1472 三角面 / 60fps；原子模型 19 calls / ~3.3 万三角面 / 60fps

### 新增学习功能
- 原子模型：点击核/电子层热区弹信息卡（2n² 容量、价层标记）、K/L/M 壳层标注开关、聚焦原子核、平移
- 3D 周期表：点立方体弹详情卡（8 项性质+用途+柱高数值）、跳转搜索（符号/中文/英文/序数）、上下元素导航、族/周期地面标注开关、选中悬浮名牌、同周期同族联动提亮、搜索联动压暗非命中

### 关键实现
- `src/three/gl.ts`：createRenderer / teardownRenderer / disposeSubtree / PerfGuard / exposeDebug（DEV 下挂 window 供探针读取）
- `src/three/label.ts`：Sprite 文字标注，全局缓存仅限静态文本；`userData.shared` 标记防止误释放
- `scripts/perf3d.mjs`：性能探针（renderer.info + FPS）
- 冒烟测试 39 项全绿，含反复开关 6 次无上下文泄漏

### 教训
- 跨组件复用的纹理必须显式标记 shared，否则被单个组件的销毁流程误删
- 模板字符串里写 `[i]` 不会插值，CDP evaluate 表达式中的循环变量要 `${i}`
- three r187 克隆纹理共享 source 时按 cacheKey（不含 offset/repeat）复用同一 GPU 纹理——这是图集方案成立的基础

## 3D 交互缺陷修复（第二轮）

### 根因与修复
1. **滚轮缩放失效（原子模型）**：tick 里无条件把相机距离 lerp 回 `desiredDistance`；而滚轮只瞬时触发 OrbitControls 的 start/end，下一帧 `dragging` 已为 false，缩放立刻被拉回。→ 改为「按需动画」：`distanceAnim: number|null`，仅聚焦/重置/切元素时启用；controls 'start' 取消动画，'end' 用 `syncUserZoom()` 记录用户倍率（窗口缩放按比例还原）。
2. **「下一个」总是氦 / 「上一个」无响应（3D 立方）**：详情卡是 `.canvas-host` 的内部覆盖层，pointerup 冒泡到 host 的拾取逻辑 → 未命中就清空 `picked` → 卡片卸载 → click 再也找不到按钮节点。→ `fromCanvas(ev)` 只处理 `ev.target === canvas` 的事件。
3. **导航按钮 disabled**：`:disabled="!picked && !selected"` 初始即禁用。→ 引入 `currentNumber = picked?.number ?? selected ?? 1`，仅在 1 / 118 边界置灰（不循环）。
4. **卡片资料看不到 / 按钮被挤出可视区**：内容溢出（scrollHeight 569 > clientHeight 498），导航按钮落在裁剪区外，elementFromPoint 命中的是页面容器。→ 卡片改 flex 列：`.card-scroll`（可滚）+ `.card-foot`（操作与导航常驻）；补电子排布、各层电子数、族/周期/区、发现年份。
5. **视图偏移无法回中心**：`focusElement` 把 `controls.target` 移到元素身上，自转随之偏离；原 `resetView` 为硬切且不够显眼。→ `flyTo()` 平滑动画 + 导航栏新增「⌖ 回到中心」；controls 'start' 取消飞行。

### 顺带修复
- 选中悬浮名牌在近距离聚焦时过大（Sprite 世界尺寸固定）→ 按相机距离补偿缩放 `0.46 * clamp(dist/10, 0.55, 1.6)`；`setLabelText` 现在返回 aspect。
- `exposeDebug` 参数类型放宽为 unknown，新增 `__EC_ATOM_DBG__ / __EC_CUBE_DBG__`（camera/controls/limits）供测试读取。

### 验证
- 新增 `scripts/verify3d.mjs`（`pnpm verify`）：24 项，覆盖缩放可放大/缩小、上下限（min 2.83 / max 43.01）、重置回构图距离、序数递增递减、1 与 118 边界禁用、回到中心（target 归 [0,0.6,0]、半径 21.04）、拖拽旋转、卡片内点击不误关、点击空白仍可关、窗口缩放、零控制台错误 —— 全绿。

### 原子核渲染（新模块 src/three/nucleus.ts）
- 旧问题：单个质子偏心（斐波那契球第一点在 +Y 轴上）、1~4 个核子时间距过大显松散、核子半径恒 0.155 不随数量自适应。
- 算法：①单位空间（核子半径=1）packing——斐波那契球/面心立方晶格多初值 + 两两排斥 + 退火收缩（LAMBDA0=0.012, STRENGTH=0.5），得中心距≥2 的簇；小 n 多轮重启取最紧解（n=6 偏优 0.9%，n≤8 用 40 次、n≤14 用 24、n≤24 用 16、n≤60 用 6、更大只用 FCC 晶格）。②核子半径 0.18→0.105 双曲收敛，等比缩放由构造保证不重叠。③质心归零保证居中。结果按核子数缓存（Og 294 首算 ~40ms，命中 0.1ms）。
- AtomModel3D.vue：单位球几何+实例缩放、细分随核子数自适应（20/14/10 段）、核热区下限 0.22、标注贴核表面 0.34、层间隙 0.62+0.3×核半径（SPAN 4.6）、电子用独立 tmpElectron（防止继承核子实例缩放）、__EC_ATOM_DBG__ 新增 nucleus()。
- 数值：dmin/2≥0.9999 不重叠、质心~1e-8、核半径 0.18(H)→0.918(Og)。
- 回归：verify-theme 13/13、verify3d 24/24、smoke 39/39 全绿；H/He/Li/C/Fe/Ag/Au/U/Og 截图与聚焦视角人工确认（截图在 .screenshots/nuc-*.png）。verify3d.mjs 导航 URL 支持 EC_URL 覆盖。
